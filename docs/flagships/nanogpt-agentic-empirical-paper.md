# Moved: Nanochat Agentic Empirical Paper

The former NanoGPT agentic-paper scaffold was never validated as a real
NanoGPT training workflow and has been retired. It is not a compatibility
alias: Nanochat has a different runtime, tokenizer/data pipeline, evaluation
metric, and GPU-image contract.

Use the [Nanochat agentic empirical paper](./nanochat-agentic-empirical-paper.md)
runbook for all new work. It pins the Nanochat repository, records
`validation_bits_per_byte`, and requires a reviewed immutable GPU image before
any live Modal job is authorized.
